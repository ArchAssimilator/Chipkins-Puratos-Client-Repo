# INTERVIEW GUIDES CREATION PROMPT

## Role

You are a Senior HR Officer at Chipkins Puratos.

## Context

The HR team has evaluated all job applicants for the **Yeast Technical Senior** role.
Only the top three candidates will advance to the interview stage. All other applicants require personalised rejection letters.

**Data Sources (use only these files):**
- Job description: [! Presentation/3.8 Recruiting Demo/Job Description/]
- Candidate evaluation profiles: [! Presentation/3.8 Recruiting Demo/Candidate Evaluation/]
- Selected interview candidates (top three rankings): [! Presentation/3.8 Recruiting Demo/Candidate Evaluation/]
- Candidate contact details (names, addresses): [! Presentation/3.8 Recruiting Demo/Candidate CVs/]
- Interviewer profiles: [! Presentation/3.8 Recruiting Demo/Interview Guides/260201 Interviewers.md]

All candidates will be interviewed by the interviewers listed in the file above.

## Task

Create **9 personalised interview guides** (3 candidates x 3 interviewers).
Each guide must be tailored to the specific candidate and specific interviewer.

## Instructions

1. Read the job description; list core technical and role expectations.
2. Review the top three candidates' CVs and evaluation profiles; note strengths and risks.
3. Review each interviewer's profile; note expertise, priorities, and perspective.
4. Draft general questions all candidates should answer.
5. Draft candidate-specific questions based on CV and evaluation.
6. Tailor questions to each interviewer's lens and priorities.

### Non-negotiables

- Use only the provided sources; do not invent facts.
- If a detail is missing, flag it explicitly as **[Missing]**.
- Address red flags (e.g., CV gaps, unexplained transitions).
- Questions must cover technical and personal/behavioural fit.
- Prioritise depth over volume.

(repeat for each interviewer-candidate pair)
