## How to Use
- Run each prompt in order.
- Starting at Step 2, each prompt explicitly asks you to paste the prior step's "Context Capsule" at the top under "Context Capsule Input".
- After each step, paste the new "Context Capsule" into the next step to keep context short.
- Pause after Step 0 to answer intake questions before proceeding.
